# 아테온 온라인 — 설치 안내 (안드로이드)

친구에게 받은 링크로 설치하는 테스트 버전입니다. 구글 플레이에는 아직 없습니다.

## 설치하기 (처음 한 번)

1. 휴대폰에서 아래 **최신 버전** 링크를 눌러 APK 파일을 받습니다. (파일이 커서 Wi-Fi를 권합니다)
2. 받은 파일을 누르면 「알 수 없는 앱 설치」를 허용하겠느냐고 묻습니다 → **허용**하고 돌아옵니다. (처음 한 번만)
3. 「Play 프로텍트」 경고가 뜨면 **「무시하고 설치」**(또는 「자세히 → 설치」)를 누릅니다.
4. 설치가 끝나면 「아테온 온라인」를 켭니다.

## 업데이트하기

새 버전이 나오면 게임을 켤 때 **「업데이트 받기」** 창이 뜹니다. 누르면 새 APK를 받고, 위 2~3번처럼 설치하면 됩니다. 저장된 기록은 그대로입니다.

## 두 가지 버전

| | 온라인판 | 체험판 |
|---|---|---|
| 파일 이름 | `ateon-<버전>-online.apk` | `ateon-<버전>-trial.apk` |
| 서버 | 서버가 켜져 있을 때만 플레이 가능 (채팅·우편·친구·뽑기 포함) | 서버 없이 혼자 플레이 |
| 범위 | 전체 | 1장까지, 뽑기·순위·우편·채팅 없음 |
| 기록 | 서버에 저장 | 휴대폰에만 저장, 온라인판으로 옮길 수 없음 |

- 기록은 **휴대폰마다 따로** 저장됩니다. 온라인판은 설정 → 계정에서 「기기 이전 코드」로 다른 휴대폰에 옮길 수 있습니다.
- 온라인판에서 「서버에 연결할 수 없습니다」가 뜨면 서버가 꺼진 시간입니다. 잠시 뒤 다시 켜 보세요.
